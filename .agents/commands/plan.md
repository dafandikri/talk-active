description: Draft a short implementation plan for a task before any code is written.
---

Produce a concise plan for: $ARGUMENTS

1. Restate the goal in one sentence.
2. List the concrete steps (smallest viable change first).
3. Call out risks, unknowns, and the validation command(s) that will prove it works.
4. If the plan is clearer shown than told, build it as an interactive artifact with the
   `lavish` skill instead of prose.

Stop and get approval before implementing.
