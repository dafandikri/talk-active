# Assets

**Source of truth. Never put an original here's only copy in `public/` — that directory is
generated by `scripts/build-public.mjs`, which deletes it on every build, and it is
gitignored. Files placed there are one `pnpm build` away from being gone for good.**

## Layout

```
src/assets/
  brand/     the logo and its lockups — used in chrome, never decorative
  mascot/    Kato, the blue-and-gold macaw — used to carry a state or a mood
  <root>     event logos, QR codes, and one-off marks
```

## Naming

A filename says **what the image is**, then **which variant**, with no abbreviations:

| Good | Why |
|---|---|
| `talk-active-logo-horizontal.svg` | subject, then arrangement |
| `kato-macaw-questioning.svg` | character, species, state |
| `ristek-hackathon-2026-logo.png` | owner, year, kind |

Avoid `logo-w-text.svg`, `log-w-motto.svg`, `kato-group.svg`: `w` is ambiguous, `log` was a
typo that shipped, and `group` describes the file's arrangement rather than its content.

## The bird is a macaw

Blue wings, yellow breast, green forehead, black beak, no crest — *Ara ararauna*, a
blue-and-gold macaw. Not a cockatoo, which is white or pink and wears a head crest. The
filenames say `macaw` so that anyone searching the repo finds every related asset at once,
and so they agree with `macaw-mascot-3d.webp`, which predates them.

## Weight

The four mascot files are **~1 MB each**: they are PNGs wrapped in an SVG envelope, not
drawn vectors — one `<image>` element, zero `<path>`. The brand files are true vector
(35–110 KB, 35–41 paths) and can be used anywhere without thought.

Before putting a mascot file on a page that a visitor loads over mobile data at the booth,
export a sized raster instead. `macaw-mascot-3d.webp` is 80 KB and carries the same picture;
swapping it for the 1 MB SVG is a twelvefold regression for no visible gain.

## Publishing

Anything a shipped page references must be listed in `PUBLIC_RUNTIME_FILES` in
`scripts/build-public.mjs`. A file that is imported but not listed 404s in production and, if
it is a module, stops the whole application from starting. `test/deployment-artifact.test.mjs`
walks the real reference graph and fails when that happens.
